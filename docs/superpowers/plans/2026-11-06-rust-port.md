# Rust Desktop Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship the existing desktop experience as a separate Rust + Tauri app.
**Architecture:** A platform-independent chem-core crate owns chemistry, catalog
loading and persistence. Vue calls thin Tauri commands; native CI builds releases.
**Tech Stack:** Rust, serde, tagged YAML, reqwest, Tauri 2, Vue 3, Vite.
**Spec:** docs/superpowers/specs/2026-11-06-rust-port-design.md

## Global Constraints
- Independent ignored nested Git repository; binaries only in Releases.
- Keep Vue behavior and original non-commercial license; no Python runtime.
- Stable IDs, valid cached fallback, persistent favorites, finite quantities.

## Review Focus
- Shared intermediate reagents must sum across every branch.
- Zero/NaN/infinite quantities and cyclic recipes must return errors.
- Unknown YAML effects must not prevent recipe loading.
- A failed download or malformed replacement must keep valid cached recipes.
- Immediate close after adding a favorite must not lose the acknowledged save.
