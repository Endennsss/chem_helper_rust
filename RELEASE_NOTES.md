Chem Helper Rust 1.1.0 — полный каталог химических реакций Sunrise.

- Без Python, FastAPI и локального HTTP-сервера.
- Очередь, избранное и настройки хранятся в постоянном файле данных; закрытие ожидает сохранения.
- Исправлен недосчёт общих промежуточных веществ в пошаговых рецептах.
- Катализаторы показываются отдельно от расходуемых ингредиентов.
- Поддерживаются YAML-теги SS14, большие неиспользуемые метаданные и BOM во входных файлах.
- Все 386 реакций в 13 категориях доступны сразу, включая первый запуск без сети.
- Сохранены альтернативные рецепты, 66 реакций без жидкого продукта и 31 реакция с несколькими продуктами.
- Поиск по названию, ID реакции и исходным реагентам; фильтр категорий со счётчиками.
- В инструкциях показаны продукты, оборудование, специальные эффекты и нижняя/верхняя температура.
- Дробные объёмы сохраняются. Реакции без жидкого продукта считаются в порциях; дискретные реакции требуют целых порций. Порции и объёмы в очереди считаются отдельно.
- Очередь и избранное переходят на ID реакций. Старый кеш 35/87 рецептов больше не скрывает полный каталог; отсутствующие старые рецепты сохраняются в данных.
- Фоновое обновление проверяет все YAML-файлы прототипов и русскую локализацию одной ревизии. Неполный список или неудачная загрузка не заменяют рабочий кеш. Проверка новой ревизии может занять несколько минут.
- Некорректная дробная дискретная порция больше не попадает в очередь и не блокирует её расчёт.
- Linux и Windows собираются отдельными нативными GitHub Actions runners; тесты выполняются на обеих системах.

Windows: NSIS-установщик или portable `chem-helper-rust.exe`. Для окна нужен Microsoft Edge WebView2 Runtime.
Linux: `.deb` или AppImage; сборка на Ubuntu 24.04. Старые дистрибутивы могут иметь несовместимые системные библиотеки.
`SHA256SUMS.txt` содержит контрольные суммы вложений.

Снимок: Sunrise `87c75a47e4f9ef9eb6d8fc6a8f759a1b3fba900c`, 3806 проверенных YAML-файлов, 19 файлов реакций. Манифест покрытия: `crates/chem-core/data/coverage.json`.

Очередь, избранное и настройки Rust-версии сохраняются при обновлении. Состояние Python-версии автоматически не переносится.
