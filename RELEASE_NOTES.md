Первая отдельная версия Chem Helper на Rust + Tauri 2 с сохранённым Vue-интерфейсом.

- Без Python, FastAPI и локального HTTP-сервера.
- Очередь, избранное и настройки хранятся в постоянном файле данных; закрытие ожидает сохранения.
- Исправлен недосчёт общих промежуточных веществ в пошаговых рецептах.
- Катализаторы показываются отдельно от расходуемых ингредиентов.
- Поддерживаются YAML-теги SS14, большие неиспользуемые метаданные и BOM во входных файлах.
- 35 встроенных рецептов для первого офлайн-запуска; фоновое онлайн-обновление до 87 рецептов и постоянный кеш.
- Linux и Windows собираются отдельными нативными GitHub Actions runners; тесты выполняются на обеих системах.

Windows: NSIS-установщик или portable `chem-helper-rust.exe`. Для окна нужен Microsoft Edge WebView2 Runtime.
Linux: `.deb` или AppImage; сборка на Ubuntu 24.04. Старые дистрибутивы могут иметь несовместимые системные библиотеки.
`SHA256SUMS.txt` содержит контрольные суммы вложений.

Состояние Python-версии автоматически не переносится: это отдельное приложение с собственным каталогом данных.
