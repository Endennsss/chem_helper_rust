# Chem Helper Rust

Помощник по химии Space Station 14 / Рыбья Станция. Отдельная версия на
**Rust + Tauri 2 + Vue 3**, без Python и локального HTTP-сервера.

## Возможности

- Каталог, поиск, очередь, избранное, пошаговое приготовление и температуры.
- Rust рассчитывает ингредиенты и суммирует общие промежуточные вещества.
- Катализаторы показываются отдельно и не включаются в расход реагентов.
- Избранное, очередь и настройки сохраняются атомарно в `state.json` внутри
  системного каталога данных приложения `com.endennsss.chem-helper-rust`.
  Закрытие окна ожидает завершения сохранения. Повреждённый файл сохраняется
  как `.corrupt`, прежде чем начнётся восстановление.
- Все 386 реакций Sunrise доступны на чистой установке без сети: 13 категорий,
  альтернативные рецепты, реакции без жидкого продукта и с несколькими продуктами.
  Поиск работает по названию, ID реакции и исходным реагентам.
- Количество означает объём продукта или всей выходной смеси. Реакции без
  жидкого продукта считаются в порциях; для дискретных реакций нужны целые
  порции. Дробные объёмы сохраняются, выход дискретных реакций округляется вверх.
- В инструкции показаны все продукты, катализаторы, границы температуры,
  нужное оборудование и специальные эффекты. Готовые компоненты для разделения
  и взаимозависимых процессов отмечаются отдельно.
- При наличии сети каталог обновляется из Sunrise в фоне. YAML и русская
  локализация загружаются из одной ревизии; проверяются все YAML-файлы прототипов,
  включая серверные папки. Полная проверка новой ревизии может занять несколько
  минут. Ошибка загрузки или неполный ответ GitHub сохраняет прежний каталог.
- Старый кеш из 35/87 рецептов заменяется полным встроенным каталогом.
  Очередь и избранное переходят на стабильные ID реакций; отсутствующие в Sunrise
  старые рецепты остаются в сохранённых данных и отмечаются при попытке добавить.
- Источник и кнопка обновления каталога находятся в Настройках.

## Установка

Готовые файлы доступны в [Releases](https://github.com/Endennsss/chem_helper_rust/releases).
Windows: установщик NSIS или portable `.exe`; нужен Microsoft Edge WebView2.
Linux: `.deb` или AppImage. Tauri использует системный WebKitGTK, поэтому
системные зависимости и совместимость дистрибутива имеют значение.

## Разработка

Установите Node.js 24+, Rust stable (минимум 1.90) и
[зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

```sh
npm ci
npm run tauri -- dev
```

```sh
cargo test -p chem-core --locked
npm test
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run tauri -- build
```

Проверка всех онлайн-рецептов вручную (нужна сеть):

```sh
cargo run -p chem-core --example inspect -- --online
```

Для принудительной повторной проверки всех файлов добавьте `--force`.

`npm run dev` запускает только Vite; native-команды доступны при запуске через
Tauri. Веб-версия с отдельным сервером в этот репозиторий не входит.

Нативный smoke-тест интерфейса (нужны `tauri-driver` и WebKitWebDriver):

```sh
npm run tauri -- build --debug --no-bundle
# Запустите tauri-driver с отдельным XDG_DATA_HOME, чтобы не трогать свой профиль.
node tests/desktop-smoke.mjs
```

Тест проверяет полный офлайн-каталог, категории, холодный синтез, несколько
продуктов, оборудование, защиту очереди от дробных дискретных порций, смешанные
единицы и избранное. После перезапуска проверяется восстановление данных.

## Структура

- `crates/chem-core` — расчёты, YAML/FTL, онлайн-обновление, кеш и сохранение.
- `src-tauri` — нативное окно, команды и конфигурация упаковки.
- `frontend` — исходный Vue-интерфейс, адаптированный для native-команд.
- `.github/workflows/release.yml` — тесты и сборки на настоящих Linux/Windows
  runners; публикация релиза при push тега `v*`.

`target`, `node_modules`, собранный интерфейс, кеш и релизные файлы в Git не
попадают. `Cargo.lock` и `package-lock.json` фиксируют зависимости.

## Данные и лицензия

Оригинальная программа: [Ende / Chem Helper](https://github.com/Endennsss/chem_helper).
Источник рецептов и локализации:
[space-sunrise/sunrise-station](https://github.com/space-sunrise/sunrise-station).
Встроенный нормализованный снимок основан на ревизии
`87c75a47e4f9ef9eb6d8fc6a8f759a1b3fba900c`: проверены 3806 YAML-файлов,
386 ID реакций в 19 файлах, включая `_Sunrise/Chemistry/Recipes`.
66 реакций не имеют жидкого продукта, 31 — имеют несколько продуктов.
Исходные YAML/FTL, описания и исходники метаболизма в снимок не включены;
сохранены идентификаторы, числовые коэффициенты и краткие подписи.
Ревизия, список ID и распределение по файлам находятся в
`crates/chem-core/data/coverage.json`; снимок — в `sunrise-catalog.json` рядом.
Для воспроизведения снимка из полного checkout нужной ревизии:

```sh
cargo run -p chem-core --example build_snapshot -- /path/to/sunrise-station
```

Онлайн-каталог кешируется локально у пользователя. Это неофициальный игровой помощник.
