# Chem Helper Rust

Помощник по химии Space Station 14 / Рыбья Станция. Отдельная версия на
**Rust + Tauri 2 + Vue 3**, без Python и локального HTTP-сервера.

## Возможности

- Каталог, поиск, очередь, избранное, пошаговое приготовление и температуры.
- Rust рассчитывает ингредиенты и суммирует общие промежуточные вещества.
- Катализаторы показываются отдельно и не включаются в расход реагентов.
- Избранное, очередь и настройки сохраняются атомарно в `state.json` внутри
  системного каталога данных приложения `com.endennsss.chem-helper-rust`.
  Закрытие окна ожидает завершения сохранения. Повреждённый файл сохраняется
  как `.corrupt`, прежде чем начнётся восстановление.
- 35 встроенных исходных рецептов работают на чистой установке без сети.
  При наличии сети каталог обновляется из Sunrise в фоне; последний валидный
  каталог сохраняется для офлайн-работы. Текущий онлайн-каталог — 87 рецептов.
- Источник и кнопка обновления каталога находятся в Настройках.

## Установка

Готовые файлы доступны в [Releases](https://github.com/Endennsss/chem_helper_rust/releases).
Windows: установщик NSIS или portable `.exe`; нужен Microsoft Edge WebView2.
Linux: `.deb` или AppImage. Tauri использует системный WebKitGTK, поэтому
системные зависимости и совместимость дистрибутива имеют значение.

## Разработка

Установите Node.js 24+, Rust stable (минимум 1.90) и
[зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

```sh
npm ci
npm run tauri -- dev
```

```sh
cargo test -p chem-core --locked
npm test
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run tauri -- build
```

Проверка всех онлайн-рецептов вручную (нужна сеть):

```sh
cargo run -p chem-core --example inspect -- --online
```

`npm run dev` запускает только Vite; native-команды доступны при запуске через
Tauri. Веб-версия с отдельным сервером в этот репозиторий не входит.

## Структура

- `crates/chem-core` — расчёты, YAML/FTL, онлайн-обновление, кеш и сохранение.
- `src-tauri` — нативное окно, команды и конфигурация упаковки.
- `frontend` — исходный Vue-интерфейс, адаптированный для native-команд.
- `.github/workflows/release.yml` — тесты и сборки на настоящих Linux/Windows
  runners; публикация релиза при push тега `v*`.

`target`, `node_modules`, собранный интерфейс, кеш и релизные файлы в Git не
попадают. `Cargo.lock` и `package-lock.json` фиксируют зависимости.
